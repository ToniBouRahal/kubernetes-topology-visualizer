{{ include "topology.fullname" . }} installed into namespace {{ .Release.Namespace }}.

Cluster ID: {{ .Values.clusterId }}
  This value is embedded in every node ID and MUST match on the agent and the backend.
  It is templated from one chart value, so it cannot drift unless you override it twice.

1. Wait for readiness:

     kubectl -n {{ .Release.Namespace }} rollout status ds/{{ include "topology.fullname" . }}-agent
     kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "topology.fullname" . }}-backend

2. Confirm an agent pod is running on EVERY node (control-plane included):

     kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/component=agent -o wide

3. Open the UI (port-forwarding is the default access method for kind):

     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "topology.fullname" . }}-frontend {{ .Values.frontend.service.port }}:{{ .Values.frontend.service.port }}
     open {{ .Values.auth.externalUrl | default (printf "http://localhost:%v" .Values.frontend.service.port) }}
{{- if and .Values.auth.enabled .Values.auth.dex.enabled }}

   Sign in with the bundled Dex (ADR-014 D-14.7):
     user:     {{ .Values.auth.dex.email }}
     password: kubectl -n {{ .Release.Namespace }} get secret {{ include "topology.fullname" . }}-auth -o jsonpath='{.data.demo-password}' | base64 -d; echo
{{- else if .Values.auth.enabled }}

   Sign in through {{ .Values.auth.oidc.issuerUrl }}. The redirect URI registered with it must be
   exactly: {{ trimSuffix "/" .Values.auth.externalUrl }}/oauth2/callback
{{- end }}

4. The API is served only over mutual TLS (ADR-014 D-14.3). Outside the UI, use the frontend's
   client certificate — reading it needs Secret access in this namespace, which is the point:

     kubectl -n {{ .Release.Namespace }} get secret {{ include "topology.fullname" . }}-tls-frontend -o json \
       | jq -r '.data["tls.crt"], .data["tls.key"], .data["ca.crt"]' | ...   # see docs/operator-guide.md
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "topology.backendService" . }} {{ .Values.backend.service.apiPort }}:{{ .Values.backend.service.apiPort }}

   `make api-get API_PATH=/api/v1/graph?window=5m` does all of this for the kind demo.

An empty graph is the normal first state. Generate traffic and allow up to 20 seconds:
agent aggregation is {{ .Values.agent.flushIntervalSeconds }}s, plus a 5s UI poll.
